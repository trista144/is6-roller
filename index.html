        HOW TO SCAN

        怎么把 box 读进来

        1. 手机或 PC 打开游戏 干员 列表，把六星所在的部分滚动截屏，尽量一屏 8 个、两行。
        2. 把截图丢进程序目录的 screenshots 文件夹。
        3. 双击 识别box.bat（或运行 python tools/recognize_box.py）。
        4. 回来刷新本页面，约束面板里就会显示识别到的干员。

        识别用的是 Windows 自带的离线 OCR，不上传任何图片。名字认错会自动对照干员表纠正；认不出的卡不会进入禁选池，所以名单里缺人可以再补一张截图重新识别。

        这一步需要 Windows 电脑 + Python 3；手机端暂时做不了。想在手机上抽签（含禁选），可以让跑过识别的电脑生成「我的 box」单文件版，把那个 HTML 发到手机。
