        想让禁选更准确（带上等级），再走截图识别：

        1. 游戏里打开 干员 列表，把六星所在部分滚动截屏；

        4. 回来刷新页面，干员池会自动按识别结果初始化。

        识别用 Windows 自带的离线 OCR，不上传图片。需要 Windows 电脑 + Python 3，手机端暂时做不了。
